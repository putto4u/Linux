우분투 서버 22.04(Jammy Jellyfish) 설치 과정을 단계별로 분석하여, 향후 다양한 서버 서비스를 운영하기에 최적화된 가이드를 제공합니다.

## Ubuntu Server 22.04 설치 가이드: 단계별 설정과 최적화

VM 환경에서 우분투 서버를 설치할 때 마주하게 되는 각 단계의 의미와 권장 설정값입니다.

### 1. 초기 기본 설정 (Language & Keyboard)

* **Choose your language:** 설치 프로세스에서 사용할 언어입니다. 서버 환경에서는 오류 메시지 검색 및 커뮤니티 트러블슈팅의 편의성을 위해 **[English]**를 강력히 권장합니다.
* **Keyboard Configuration:** 레이아웃 설정입니다. 일반적인 경우 **English (US)**를 선택합니다.

### 2. 설치 유형 및 네트워크 (Installation Type & Networking)

* **Choose type of install:** * **Ubuntu Server:** 표준 설치입니다. (권장)
* **Ubuntu Server (minimized):** 최소 설치 버전으로, 꼭 필요한 패키지만 포함되어 가볍지만 수동 설정이 많아집니다.


* **Network Connections:** * **DHCP:** VM에서 자동으로 IP를 할당받습니다.
* **Static IP 설정 방법:** 나중에 웹 서버나 DB 서버로 운영할 계획이라면 고정 IP가 유리합니다. 인터페이스(예: eth0, ens33)를 선택하고 `Edit IPv4`에서 `Manual`로 변경하여 수동 입력합니다.



### 3. 스토리지 구성 (Storage Configuration) - **중요**

서버 서비스 확장성을 결정짓는 가장 중요한 단계입니다.

* **Guided storage configuration:**
* **[X] Use an entire disk:** 전체 디스크 사용.
* **[X] Set up this disk as an LVM group:** 반드시 체크하세요. **LVM(Logical Volume Manager)**을 사용해야 나중에 용량이 부족할 때 디스크를 추가하여 쉽게 확장할 수 있습니다.
* **[ ] Encrypt the LVM group with LUKS:** 보안이 극도로 중요하지 않다면 체크 해제합니다. (부팅 때마다 비밀번호를 입력해야 하므로 원격 관리가 어려울 수 있음)


* **FILE SYSTEM SUMMARY:** * **주의:** 기본 설정 시 우분투는 전체 용량의 일부만 `/`에 할당하고 나머지를 여유 공간으로 남겨둡니다. 나중에 수동으로 늘릴 수 있지만, 설치 단계에서 전체 용량을 사용하고 싶다면 해당 볼륨 크기를 수정해야 합니다.

### 4. 프로필 및 서비스 설정 (Profile Setup & SSH)

* **Profile Setup:** * **Your name / Server's name / Username / Password:** 실제 로그인에 사용할 계정 정보입니다. 보안을 위해 `root` 대신 고유한 사용자명을 사용하세요.
* **SSH Setup:** * **[X] Install OpenSSH server:** **필수 체크**. 서버 설치 후 원격(Putty, MobaXterm 등)에서 접속하기 위해 반드시 필요합니다.

### 5. 추가 소프트웨어 (Featured Server Snaps)

* 설치 중 패키지를 선택할 수 있는 화면이 나옵니다 (Docker, microk8s, nextcloud 등).
* **추천:** 가급적 여기서 설치하지 말고, OS 설치 완료 후 필요한 시점에 직접 `apt`나 `snap`으로 설치하는 것이 종속성 관리와 버전 선택 측면에서 훨씬 깔끔합니다. **그대로 Done을 눌러 통과하세요.**

---

### 서버 서비스를 위한 최종 체크리스트

1. **LVM 사용 유무:** 추후 서비스 데이터 증가에 대비해 무조건 LVM을 선택했는지 확인하세요.
2. **업데이트 설치:** 설치 마지막 단계에서 `Install security updates`가 진행됩니다. 완료 후 `Reboot Now`를 누르기 전 ISO 파일을 언마운트(Disconnect)해야 다시 설치 화면으로 돌아가지 않습니다.
3. **고정 IP 예약:** VM 설정에서 해당 VM의 MAC 주소에 대해 고정 IP를 예약해두면 관리가 매우 편해집니다.
