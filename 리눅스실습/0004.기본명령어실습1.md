## Linux 기본 명령어 및 경로 이해 실습 문제

**[주의사항]** 모든 실습은 가상 머신(VM) 환경의 터미널에서 진행하십시오. 중요한 시스템 파일을 삭제하지 않도록 주의가 필요하며, 실수로 시스템이 손상될 경우 앞서 배운 **스냅샷 복구** 기능을 활용하십시오.

### **1단계: 경로 및 목록 확인 (Level 1)**

1. 현재 본인이 작업 중인 디렉토리의 절대 경로를 확인하는 명령어를 입력하세요.
2. 최상위 디렉토리인 루트()로 이동하세요.
3. 루트 디렉토리에 어떤 폴더들이 있는지 상세 정보()를 포함하여 확인하세요.
4. 다시 현재 사용자의 홈 디렉토리()로 한 번에 이동하세요.
5. 홈 디렉토리 내에 숨겨진 파일들까지 모두 포함하여 목록을 출력하세요.

### **2단계: 디렉토리 생성 및 이동 (Level 2)**

6. 홈 디렉토리에 `Linux_Lab`이라는 새 폴더를 생성하세요.
7. 생성한 `Linux_Lab` 폴더 안으로 이동하세요.
8. `Linux_Lab` 폴더 안에 `Level1`, `Level2`, `Level3`라는 3개의 하위 폴더를 각각 생성하세요.
9. 현재 위치(`Linux_Lab`)에서 `Level1` 폴더로 이동한 뒤, 다시 상위 폴더로 돌아오세요.
10. `mkdir`의 옵션을 사용하여 `Test/Sub1/Sub2`라는 계층 구조를 한 번에 생성하세요.

### **3단계: 경로 표현 활용 (Level 3)**

11. 상대경로 기호를 사용하여 현재 위치에서 바로 위 부모 디렉토리로 이동하세요.
12. 절대경로를 사용하여 사용자의 홈 디렉토리 내 `Linux_Lab` 폴더로 이동하세요.
13. `Level2` 폴더로 이동한 상태에서, 상대경로를 이용해 옆에 있는 `Level3` 폴더로 이동하세요.
14. 최근에 방문했던 직전 디렉토리로 돌아가는 단축 명령어를 입력하세요.
15. 루트() 디렉토리 아래에 있는 `etc` 폴더의 내용을 현재 위치를 옮기지 않고 조회하세요.

### **4단계: 파일 삭제 및 관리 (Level 4)**

16. `Linux_Lab` 폴더 내에 빈 파일을 하나 생성해 보세요. (힌트: `touch` 명령어 사용)
17. 방금 만든 파일을 삭제하세요.
18. `Level1`, `Level2`, `Level3` 폴더가 들어있는 `Linux_Lab` 전체를 한 번에 삭제하세요.
19. 삭제 시 확인 메시지가 나오지 않도록 강제로 삭제하는 옵션을 포함하여 `Test` 폴더를 지우세요.
20. **[심화]** 절대경로를 사용하여 `/tmp` 디렉토리 내의 모든 내용을 확인해 보세요.

## 실습 문제 정답 및 해설

실습을 모두 마친 후 본인의 답변과 대조해 보시기 바랍니다.

| 번호 | 정답 명령어 | 해설 |
| --- | --- | --- |
| **1** | `pwd` | Present Working Directory의 약자로 현재 위치 출력 |
| **2** | `cd /` | `/`는 최상위 루트를 의미함 |
| **3** | `ls -l` | `-l` 옵션은 상세 정보를 리스트 형태로 출력 |
| **4** | `cd ~` 또는 `cd` | `~`는 현재 로그인한 사용자의 홈 디렉토리를 상징 |
| **5** | `ls -a` 또는 `ls -al` | `-a` 옵션은 `.`으로 시작하는 숨김 파일을 표시함 |
| **6** | `mkdir Linux_Lab` | 새로운 디렉토리 생성 |
| **7** | `cd Linux_Lab` | 해당 디렉토리로 작업 위치 변경 |
| **8** | `mkdir Level1 Level2 Level3` | 공백을 구분자로 여러 폴더 동시 생성 가능 |
| **9** | `cd Level1` 이동 후 `cd ..` | `..`은 상위 디렉토리를 의미하는 상대경로 |
| **10** | `mkdir -p Test/Sub1/Sub2` | `-p`는 중간 단계 폴더가 없으면 자동 생성하는 옵션 |
| **11** | `cd ..` | 상대경로 표현식 활용 |
| **12** | `cd /home/[사용자명]/Linux_Lab` | `/`부터 시작하는 전체 주소 입력 |
| **13** | `cd ../Level3` | 부모로 올라갔다가(`..`) 다시 내려가는 방식 |
| **14** | `cd -` | 이전 작업 경로로 토글 이동 |
| **15** | `ls /etc` | `ls` 뒤에 경로를 지정하면 이동 없이 조회 가능 |
| **16** | `touch testfile` | 파일 생성을 위해 가장 많이 쓰이는 명령어 |
| **17** | `rm testfile` | 파일 삭제 명령 |
| **18** | `rm -r Linux_Lab` | 폴더 삭제 시에는 반드시 `-r` (Recursive) 옵션 필요 |
| **19** | `rm -rf Test` | `-f` (Force) 옵션은 경고창 없이 즉시 삭제 |
| **20** | `ls /tmp` | 임시 파일 저장소 내용을 절대경로로 확인 |
