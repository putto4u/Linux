VirtualBox(VirtualHost) 환경에서 Ubuntu VM 내부의 Nginx 웹 페이지가 외부 브라우저에서 보이지 않는 문제는 대부분 **네트워크 모드 설정**과 **방화벽** 문제입니다. 이를 해결하기 위한 단계별 가이드를 정리합니다.

---

## 1. VirtualBox 네트워크 설정 확인

VirtualBox의 기본 설정인 **NAT** 모드는 외부에서 VM 내부로의 직접적인 접속을 차단합니다. 이를 해결하기 위해 **어댑터 브리지**로 변경하거나 **포트 포워딩**을 설정해야 합니다.

### 방법 A: 어댑터 브리지 (추천)

VM이 공유기로부터 별도의 IP를 할당받아 호스트 PC와 동등한 네트워크 층위에 있게 됩니다.

1. VM 전원을 끕니다.
2. **설정 > 네트워크 > 어댑터 1**로 이동합니다.
3. 다음에 연결됨: **어댑터 브리지**를 선택합니다.
4. VM을 부팅한 후 `ip addr` 명령어로 새로운 IP 주소를 확인합니다.

### 방법 B: 포트 포워딩 (NAT 유지 시)

NAT 모드를 유지하면서 특정 포트만 열어주는 방식입니다.

1. **설정 > 네트워크 > 어댑터 1 > 고급 > 포트 포워딩**을 클릭합니다.
2. 새 규칙을 추가합니다:
* **프로토콜**: TCP
* **호스트 IP**: 127.0.0.1
* **호스트 포트**: 8080 (호스트 PC에서 접속할 포트)
* **게스트 IP**: (VM 내부 IP)
* **게스트 포트**: 80 (Nginx 기본 포트)


3. 설정 후 브라우저에서 `localhost:8080`으로 접속합니다.

---

## 2. Ubuntu 내부 방화벽(UFW) 설정

Ubuntu의 자체 방화벽인 UFW가 80번 포트(HTTP)를 차단하고 있을 수 있습니다.

1. **방화벽 상태 확인**
```bash
sudo ufw status

```


2. **Nginx 서비스 허용**
```bash
# HTTP(80) 포트 허용
sudo ufw allow 'Nginx Full'

# 또는 특정 포트 지정
sudo ufw allow 80/tcp

```


3. **방화벽 재시작 및 적용**
```bash
sudo ufw reload

```



---

## 3. Nginx 바인딩 설정 확인

Nginx가 특정 IP가 아닌 로컬호스트(`127.0.0.1`)에만 바인딩되어 있는지 확인해야 합니다.

1. **설정 파일 수정**
```bash
sudo nano /etc/nginx/sites-available/default

```


2. **Listen 설정 확인**
`listen 80;` 또는 `listen [::]:80;`으로 되어 있는지 확인합니다. 만약 `listen 127.0.0.1:80;`으로 되어 있다면 외부 접속이 불가능하므로 수정이 필요합니다.
3. **서비스 재시작**
```bash
sudo systemctl restart nginx

```



---

## 4. 접속 테스트 및 트러블슈팅 체크리스트

설정을 마친 후 다음 순서로 통신을 확인합니다.

| 단계 | 명령어 / 확인 사항 | 기대 결과 |
| --- | --- | --- |
| **1. VM 내부 접속** | `curl -I localhost` | HTTP/1.1 200 OK |
| **2. VM IP 확인** | `ip addr` | `192.168.x.x` 등 유효한 IP |
| **3. 호스트에서 핑 테스트** | `ping [VM_IP]` | 응답 확인 (ICMP 허용 시) |
| **4. 호스트 브라우저** | `http://[VM_IP]` | Nginx 환영 페이지 출력 |

> [!IMPORTANT]
> **AWS 환경 참고**: 만약 현재 환경을 추후 AWS EC2로 이전할 경우, **보안 그룹(Security Group)** 설정에서 인바운드 규칙(Port 80)을 반드시 추가해야 외부 접속이 가능합니다. (AWS 프리티어 이용 시 인바운드 설정 미비로 인한 접속 불가가 빈번하게 발생하며, 이는 추가 과금 요소는 아니나 필수 보안 설정 단계입니다.)
