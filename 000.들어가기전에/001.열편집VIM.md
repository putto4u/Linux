우분투 서버 환경에서 YAML 파일처럼 들여쓰기(Indentation)와 열 맞춤이 중요한 파일을 편집할 때, 가장 권장되는 터미널 기반 편집기는 **Vim(Vi Improved)**입니다.

Vim은 설정을 통해 YAML 문법 강조, 자동 들여쓰기, 가이드라인 표시 기능을 제공하여 실수를 방지해 줍니다. 또한, 최근에는 더 직관적인 사용법을 가진 **Micro** 편집기도 열 맞춤과 마우스 지원 기능 덕분에 많이 사용됩니다.

---

## 1. 강력한 표준 편집기: Vim (Vi Improved)

Vim은 기본적으로 설치되어 있는 경우가 많지만, YAML 편집을 더 편리하게 하려면 설정을 추가하는 것이 좋습니다.

### 설치 방법

```bash
sudo apt update
sudo apt install vim -y

```

### YAML 편집을 위한 최적화 설정

사용자 홈 디렉토리의 `.vimrc` 파일을 수정하여 들여쓰기 시 탭 대신 공백이 들어가도록 설정합니다.

```bash
vi ~/.vimrc

```

파일 안에 아래 내용을 복사하여 붙여넣으세요:

```vim
syntax on           " 문법 강조(하이라이팅) 활성화
set number          " 줄 번호 표시
set expandtab       " Tab을 입력하면 공백(Space)으로 변환
set tabstop=2       " Tab의 크기를 공백 2칸으로 설정 (YAML 표준)
set shiftwidth=2    " 자동 들여쓰기 크기를 2칸으로 설정
set softtabstop=2   " 백스페이스 시 2칸씩 삭제
set ai              " 자동 들여쓰기(Auto Indent) 활성화

```

## 2. 직관적인 모던 편집기: Micro

Vim의 복잡한 명령어(i, :wq 등)가 익숙하지 않다면, 윈도우 메모장처럼 `Ctrl+S`(저장), `Ctrl+C`(복사)를 그대로 사용할 수 있는 **Micro**를 추천합니다.

### 특징

* **마우스 지원**: 터미널 내에서 클릭과 드래그로 커서 이동 및 범위 선택 가능
* **문법 강조**: YAML 파일을 열면 자동으로 색상을 입혀줌
* **들여쓰기 가이드**: 열 위치를 파악하기 쉬움

### 설치 방법

```bash
sudo apt update
sudo apt install micro -y

```

### 실행 및 사용

```bash
micro /etc/netplan/01-netcfg.yaml

```

## 3. YAML 편집 시 유용한 팁

### 정적 분석 도구 (yamllint)

파일을 실행하기 전에 들여쓰기가 잘못되었거나 문법에 어긋난 부분이 없는지 검사해주는 도구입니다.

* **설치**: `sudo apt install yamllint -y`
* **검사**: `yamllint yourfile.yaml`

### Netplan 적용 전 '열' 확인법

Netplan 설정 시 가장 흔한 실수는 상위 계층(`network:`)과 하위 계층(`ethernets:`)의 시작 위치가 맞지 않는 것입니다.

* **Vim 유저**: 명령 모드에서 `:set list`를 입력하면 공백과 탭을 기호로 표시해주어 열 맞춤을 시각적으로 확인할 수 있습니다.
* **Micro 유저**: 기본적으로 하단에 현재 커서의 행(Line)과 열(Column) 위치가 숫자로 표시됩니다.
