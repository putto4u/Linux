## 온프레미스 우분투 VM에 Nginx 서비스 구축 가이드

온프레미스(자체 서버) 환경의 우분투 VM에서 Nginx를 설치하고 서비스를 활성화하는 과정은 매우 표준화되어 있습니다. 아래 단계별 절차를 통해 안정적인 웹 서버 환경을 구축할 수 있습니다.

---

### 1. 패키지 목록 업데이트 및 설치

먼저 시스템의 패키지 저장소 목록을 최신 상태로 갱신한 후 Nginx 패키지를 설치합니다.

```bash
# 1. 패키지 리스트 업데이트
sudo apt update

# 2. Nginx 설치
sudo apt install nginx -y

# 3. 설치 버전 확인
nginx -v

# 4. 서비스 확인
curl 127.0.0.1
```

---

### 2. Nginx 서비스 관리 (systemd)

설치가 완료되면 Nginx 서비스는 보통 자동으로 시작되지만, 명시적으로 제어하고 상태를 확인하는 방법이 중요합니다.

| 작업 | 명령어 | 설명 |
| --- | --- | --- |
| **시작** | `sudo systemctl start nginx` | Nginx 서비스를 수동으로 실행 |
| **중지** | `sudo systemctl stop nginx` | 실행 중인 서비스를 종료 |
| **재시작** | `sudo systemctl restart nginx` | 중지 후 다시 시작 (설정 변경 시 사용) |
| **재로드** | `sudo systemctl reload nginx` | 연결을 끊지 않고 설정 파일만 다시 읽기 |
| **상태 확인** | `sudo systemctl status nginx` | 현재 실행 상태(active/running) 확인 |
| **자동 실행** | `sudo systemctl enable nginx` | 부팅 시 Nginx가 자동으로 켜지도록 설정 |

---

### 3. 방화벽 설정 (UFW)

온프레미스 환경에서는 외부 접속을 허용하기 위해 우분투 자체 방화벽(UFW)에서 HTTP(80) 및 HTTPS(443) 포트를 개방해야 합니다.

```bash
# 1. 사용 가능한 앱 프로필 확인
sudo ufw app list

# 2. Nginx Full(80, 443 둘 다) 허용
sudo ufw allow 'Nginx Full'

# 3. 방화벽 활성화 (이미 활성화된 경우 생략 가능)
sudo ufw status
sudo ufw enable

# 4. 설정 결과 확인
sudo ufw status

```

---

### 4. 설치 확인 및 테스트

브라우저를 열고 VM의 IP 주소를 입력하여 Nginx 환영 페이지가 나오는지 확인합니다.

* **브라우저 접속**: `http://[서버_IP_주소]`
* **터미널 접속(curl)**: `curl -I localhost`

---

### 5. 주요 디렉토리 및 파일 위치

Nginx를 운영하면서 자주 다루게 될 핵심 경로입니다.

* **웹 루트 디렉토리**: `/var/www/html/` (실제 웹 페이지 파일인 `index.html`이 있는 곳)
* **메인 설정 파일**: `/etc/nginx/nginx.conf`
* **가상 호스트 설정**: `/etc/nginx/sites-available/`
* **활성화된 설정**: `/etc/nginx/sites-enabled/` (위 폴더의 파일을 심볼릭 링크로 연결)
* **로그 파일**: `/var/log/nginx/` (접속 로그 `access.log`, 에러 로그 `error.log`)

---

### 💡 실무 팁: 설정 파일 오류 검사

Nginx 설정을 수정한 후에는 서비스를 재시작하기 전에 반드시 **문법 검사**를 수행해야 합니다. 문법이 틀린 채로 재시작하면 서비스가 중단될 수 있습니다.

```bash
# Nginx 설정 파일 문법 검사
sudo nginx -t

```

> 결과가 `syntax is ok`와 `test is successful`로 나오면 안심하고 `reload` 하셔도 됩니다.
