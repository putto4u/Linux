VirtualBox에서 실행 중인 Ubuntu VM에 외부 터미널(호스트 PC의 Windows 터미널, PowerShell, CMD 등)로 접근하기 위해서는 **포트 포워딩(Port Forwarding)** 설정이 핵심입니다. 이를 통해 호스트의 특정 포트와 VM의 SSH 포트(22번)를 연결해야 합니다.

---

## 1. Ubuntu 내부 SSH 서버 설치 및 활성화

가장 먼저 VM 내부의 Ubuntu에서 외부 접속을 받아들일 준비가 되어 있어야 합니다.

1. **패키지 업데이트 및 SSH 설치**
```bash
sudo apt update
sudo apt install openssh-server

```


2. **SSH 상태 확인**
```bash
sudo systemctl status ssh

```


* `active (running)` 상태인지 확인합니다.


3. **방화벽 허용**
```bash
sudo ufw allow 22

```



---

## 2. VirtualBox 포트 포워딩 설정 (NAT 모드 기준)

VM이 'NAT' 네트워크 모드를 사용 중일 때, 호스트 PC의 특정 포트를 VM의 22번 포트로 연결하는 과정입니다.

1. VirtualBox 관리자 창에서 해당 VM 선택 -> **설정(Settings)** 클릭.
2. **네트워크(Network)** 메뉴로 이동.
3. `다음에 연결됨(Attached to)`이 **NAT**로 되어 있는지 확인 후, 하단의 **고급(Advanced)** 클릭.
4. **포트 포워딩(Port Forwarding)** 버튼 클릭.
5. 우측의 **'+' 버튼**을 눌러 새 규칙을 추가합니다.

| 항목 | 값 (권장) | 비고 |
| --- | --- | --- |
| **이름** | `SSH` | 식별용 이름 |
| **프로토콜** | `TCP` | 기본값 |
| **호스트 IP** | `127.0.0.1` | 호스트 자신을 의미 |
| **호스트 포트** | `2222` | 호스트에서 접속할 포트 (다른 서비스와 중복 금지) |
| **게스트 IP** | (비워둠) | 자동으로 할당됨 |
| **게스트 포트** | `22` | Ubuntu 내부 SSH 기본 포트 |

> **[주의]** 호스트 포트를 `22`로 설정하면 Windows 자체 서비스와 충돌할 수 있으므로 `2222` 또는 `2022` 같은 번호를 사용하는 것이 안전합니다.

---

## 3. 호스트 터미널에서 접속하기

설정이 완료되었다면 Windows 터미널을 열고 다음 명령어를 입력합니다.

```bash
# 형식: ssh [Ubuntu계정명]@[호스트IP] -p [호스트포트]
ssh username@127.0.0.1 -p 2222

```

* **username**: Ubuntu 설치 시 만든 사용자 계정 이름입니다.
* 처음 접속 시 `Are you sure you want to continue connecting (yes/no/[fingerprint])?`라는 메시지가 나오면 **yes**를 입력합니다.
* Ubuntu 계정의 비밀번호를 입력하면 접속이 완료됩니다.

---

## 4. 고정 IP 사용 시 (어댑터에 브리지)

NAT 방식이 아닌 **어댑터에 브리지(Bridged Adapter)** 모드를 사용한다면, VM이 공유기로부터 호스트 PC와 같은 대역의 독립적인 IP를 할당받습니다.

1. 설정 -> 네트워크 -> 다음에 연결됨을 **어댑터에 브리지**로 변경.
2. Ubuntu 터미널에서 `ip addr` 명령어로 할당된 IP(예: 192.168.0.50) 확인.
3. 호스트 터미널에서 바로 접속:
```bash
ssh username@192.168.0.50

```


* 이 방식은 별도의 포트 포워딩 설정이 필요 없으나, 네트워크 환경(공유기 등)에 따라 설정이 제한될 수 있습니다.



---

## 5. 트러블슈팅 및 팁

* **Connection Refused:** Ubuntu 내에서 SSH 서비스가 실행 중인지, 포트 포워딩의 게스트 포트가 22번이 맞는지 확인하세요.
* **Connection Timeout:** 방화벽(ufw)에서 22번 포트가 허용되었는지 확인하세요.
* **비밀번호 없이 접속:** 호스트 PC에서 `ssh-keygen`으로 키를 생성한 후, 공개키(`.pub`)를 Ubuntu의 `~/.ssh/authorized_keys`에 등록하면 편리합니다.
