우분투 환경에서 가장 간편하면서도 가볍게 FTP 서버를 구축할 수 있는 도구는 **vsftpd (Very Secure FTP Daemon)**입니다. 설정이 매우 단순하고 리소스를 적게 차지하여 개인용 서버나 테스트 환경에서 가장 선호되는 방식입니다.

---

## 1. vsftpd 설치

우분투 패키지 저장소에서 `vsftpd`를 설치합니다.

```bash
sudo apt update
sudo apt install vsftpd -y

```

설치가 끝나면 서비스가 자동으로 시작됩니다. 다음 명령어로 상태를 확인합니다.

```bash
sudo systemctl status vsftpd

```

---

## 2. 핵심 환경 설정 (빠른 설정)

가장 기본적인 파일 업로드와 다운로드가 가능하도록 설정 파일을 수정합니다.

```bash
sudo nano /etc/vsftpd.conf

```

파일 내에서 다음 항목들을 찾아 주석(`#`)을 제거하거나 값을 변경합니다.

* `local_enable=YES`: 로컬 사용자의 접속을 허용합니다.
* `write_enable=YES`: 파일 쓰기(업로드 및 삭제)를 허용합니다.
* `chroot_local_user=YES`: 보안을 위해 사용자가 본인의 홈 디렉토리를 벗어나지 못하게 제한합니다.

**파일 맨 아래에 다음 두 줄을 추가합니다:**

```conf
allow_writeable_chroot=YES
pasv_min_port=40000
pasv_max_port=50000

```

> **참고:** `pasv` 관련 설정은 수동 모드(Passive Mode) 전송을 위해 필요한 포트 범위를 지정하는 것입니다.

설정을 저장(`Ctrl+O`, `Enter`)하고 종료(`Ctrl+X`)한 뒤 서비스를 재시작합니다.

```bash
sudo systemctl restart vsftpd

```

---

## 3. 방화벽 허용

외부에서 접속할 수 있도록 FTP 포트와 전송용 포트를 개방합니다.

```bash
sudo ufw allow 21/tcp
sudo ufw allow 40000:50000/tcp
sudo ufw reload

```

---

## 4. 인프라 운영 및 과금 안내

우분투 서버가 설치된 위치에 따라 다음과 같은 **유료 과금** 요소가 발생할 수 있으니 주의가 필요합니다.

* **AWS EC2 트래픽 (Data Transfer Out)**: FTP를 통해 외부 사용자가 서버에서 파일을 다운로드할 경우, 사용한 트래픽 양에 따라 요금이 청구됩니다. (AWS 기준 월 100GB 무료 제공 후 초과분 과금)
* **AWS Public IPv4**: 서버 접속을 위해 할당된 공인 IP 주소는 사용 시간당 약 **$0.005**의 비용이 발생합니다.
* **EBS 스토리지**: FTP 서버에 저장되는 파일 용량이 늘어나면, 서버에 연결된 디스크(EBS)의 크기를 증설해야 하며 이에 따른 추가 월별 비용이 발생합니다.

---

## 5. 대안: Python을 이용한 즉석 FTP (설정 불필요)

별도의 데몬(Daemon) 설치 없이 현재 위치한 폴더를 즉시 FTP로 공유하고 싶을 때 매우 유용합니다.

```bash
# 관련 라이브러리 설치
pip install pyftpdlib

# 현재 폴더를 21번 포트로 즉시 공유 (쓰기 권한 포함)
sudo python3 -m pyftpdlib -p 21 -w

```

## 온프레미스용 무료 파일 서버 솔루션 TOP 3

온프레미스(자체 서버) 환경에서 비용 부담 없이 구축할 수 있는 오픈소스 기반의 파일 서버 솔루션 중 가장 검증된 3가지를 추천합니다. 사용자의 시스템 사양과 활용 목적에 따라 최적의 선택이 달라집니다.

---

### 1. TrueNAS (구 FreeNAS): 엔터프라이즈급 성능

기업용 서버 수준의 강력한 기능과 데이터 안정성을 원한다면 **TrueNAS**가 단연 최고입니다.

* **핵심 특징**: 세계 최고의 파일 시스템인 **ZFS**를 사용합니다. 데이터 손상을 스스로 복구하는 기능(Self-healing)과 무제한 스냅샷 기능을 제공합니다.
* **장점**: 안정성이 매우 높고, 플러그인을 통해 클라우드 동기화, 미디어 서버 등 확장이 쉽습니다.
* **단점**: **높은 권장 사양**(ZFS 특성상 최소 8GB~16GB 이상의 RAM 권장)이 필요하며 설정이 다소 복잡할 수 있습니다.

### 2. OpenMediaVault (OMV): 가볍고 범용적인 선택

오래된 PC나 낮은 사양의 기기(라즈베리 파이 등)를 활용하고 싶다면 **OMV**가 가장 효율적입니다.

* **핵심 특징**: 데비안(Debian) 리눅스 기반으로 제작되어 매우 가볍고 안정적입니다.
* **장점**: 하드웨어 요구사항이 낮아 저사양 PC에서도 원활하며, 웹 UI가 직관적이라 초보자도 쉽게 SMB/NFS 설정을 마칠 수 있습니다.
* **단점**: TrueNAS의 ZFS와 같은 강력한 자체 파일 관리 기능은 기본 포함되어 있지 않습니다(플러그인 필요).

### 3. Nextcloud: 구글 드라이브/드롭박스 대체용

단순한 파일 공유를 넘어, 협업 도구와 웹 인터페이스가 중요하다면 **Nextcloud**를 추천합니다.

* **핵심 특징**: "자체 구축형 클라우드"로 불립니다. 모바일 앱 지원이 강력하며 문서 편집, 캘린더 등 다양한 기능을 제공합니다.
* **장점**: 웹 브라우저와 모바일 앱을 통한 접근성이 뛰어나고 UI가 현대적입니다.
* **단점**: 엄밀히는 파일 서버(NAS OS)라기보다 애플리케이션에 가깝기 때문에, 기본 리눅스(Ubuntu 등) 위에 직접 설치하거나 도커(Docker)를 활용해야 합니다.

---

### 🔍 솔루션 한눈에 비교

| 구분 | TrueNAS CORE | OpenMediaVault | Nextcloud |
| --- | --- | --- | --- |
| **추천 대상** | 고성능/중요 데이터 보관 | 저사양 PC/간편한 구축 | 모바일 앱/협업 기능 필요 |
| **기반 OS** | FreeBSD / Debian (Scale) | Debian Linux | Linux App (Ubuntu 등) |
| **최소 RAM** | 8GB 이상 (강력 권장) | 1GB 이하도 가능 | 2GB~4GB 이상 권장 |
| **난이도** | 상 (전문 지식 필요) | 하 (직관적인 웹 UI) | 중 (리눅스 지식 필요) |

### ⚠️ 구축 시 유의사항

1. **데이터 백업**: 하드웨어 고장에 대비해 **RAID 구성**을 하거나 정기적인 외부 백업을 반드시 설정하세요.
2. **보안 설정**: 외부에서 접속할 경우 포트 포워딩보다는 **VPN(WireGuard 등)** 사용을 적극 권장합니다.
3. **디스크 관리**: 24시간 가동 시 소모품인 하드디스크의 상태를 모니터링하는 **S.M.A.R.T** 설정을 활성화하세요.
