원격 서버를 관리하기 위한 가장 표준적인 방법인 **SSH(Secure Shell)** 접속 방법은 운영체제와 인증 방식에 따라 다양합니다. 이 가이드는 터미널을 이용한 기본 접속부터 보안이 강화된 키 페어(Key Pair) 접속 방식까지 다룹니다.

---

## 1. 터미널을 이용한 기본 접속 (패스워드 인증)

Linux, macOS 또는 Windows(PowerShell/CMD)의 기본 터미널을 사용하여 접속하는 가장 일반적인 방법입니다.

### 기본 명령어 형식

```bash
ssh [사용자_계정]@[서버_IP_주소]

```

* **예시:** `ssh ubuntu@192.168.1.100`

### 포트 번호가 다른 경우 (-p 옵션)

SSH의 기본 포트는 **22번**입니다. 보안상의 이유로 포트 번호를 변경한 경우 `-p` 옵션을 사용합니다.

```bash
ssh -p 2222 ubuntu@192.168.1.100

```

---

## 2. SSH 키 페어를 이용한 접속 (보안 권장)

비밀번호 대신 디지털 키를 사용하여 접속하는 방식으로, 무차별 대입 공격(Brute-force)을 방지할 수 있는 안전한 방법입니다.

### 키 페어 생성 (로컬 PC)

```bash
ssh-keygen -t rsa -b 4096

```

* 명령어 입력 후 엔터를 치면 `~/.ssh/id_rsa`(개인키)와 `id_rsa.pub`(공개키)가 생성됩니다.

### 공개키를 서버에 등록

```bash
ssh-copy-id -i ~/.ssh/id_rsa.pub [사용자_계정]@[서버_IP_주소]

```

### 개인키를 지정하여 접속 (-i 옵션)

AWS 등 클라우드에서 내려받은 `.pem` 파일이나 생성한 개인키를 사용하여 접속할 때 필요합니다.

```bash
ssh -i /경로/to/my-key.pem ubuntu@서버_IP

```

> **주의:** 개인키 파일(`pem`)은 권한이 엄격해야 합니다. 권한 오류 발생 시 `chmod 400 my-key.pem` 명령으로 권한을 수정하십시오.

---

## 3. SSH 클라이언트 프로그램 활용

명령어 입력이 익숙하지 않거나 여러 서버를 관리해야 할 경우 전용 프로그램을 사용합니다.

* **PuTTY:** Windows에서 전통적으로 가장 많이 사용되는 무료 클라이언트입니다. (`.pem`을 `.ppk`로 변환하여 사용)
* **MobaXterm:** 터미널, SFTP, X11 포워딩 등 다양한 기능을 한 번에 제공하는 강력한 도구입니다.
* **Termius:** 모바일과 PC 간 동기화가 가능한 모던한 UI의 클라이언트입니다.

## 4. SSH 설정 및 보안 주의사항

### SSH 설정 파일 편집

서버의 SSH 동작 방식을 변경하려면 `/etc/ssh/sshd_config` 파일을 수정합니다.

```bash
sudo nano /etc/ssh/sshd_config

```

* **PasswordAuthentication no**: 비밀번호 접속을 차단하고 키 접속만 허용 (보안 강화)
* **PermitRootLogin no**: root 계정의 직접 접속을 차단

### 과금 관련 유의사항

* **AWS 공인 IP 요금**: SSH 접속을 위해 인스턴스에 할당된 **공인 IPv4 주소**는 2024년 2월 이후부터 사용 시간당 **유료 과금($0.005/hour)**이 발생합니다.
* **트래픽 비용**: SSH를 통한 단순 터미널 조작은 비용이 거의 들지 않으나, SCP/SFTP를 통해 대용량 파일을 전송할 경우 **Data Transfer Out** 요금이 발생할 수 있습니다.
